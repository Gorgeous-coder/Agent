## 多音色 bug 定位（用户 Run 日志实测）：百炼音色兼容性
- **现象**：多音色指令被识别（"✅ 已用音色「龙安洋」发送语音"），但龙小淳/龙成报 `HTTP 400 InvalidParameter [cosyvoice] Engine return error code: 4`
- **根因**：模型 `cosyvoice-v3-flash` 只支持 `longanyang`（龙安洋），`longxiaochun`/`longchen` 在 flash 上不可用
- **修复方向**：换 `ai.tts-model=cosyvoice-v3-plus`（或 v3.5-plus）；若仍报错 → 百炼控制台"语音合成→系统音色库"开通龙小淳/龙成
- **附带修复**：handleVoice 之前漏调 tryVoiceCommand（语音发送多音色指令不走），已补上（语音/文字都支持）
- 待用户明天验证：改 model 后重启测试

### 问题 1：天气简报不输出穿衣/带伞建议

### 问题 2：城市提取乱码"没找到城市「ae…±â³」"
- **根因**：WeatherBriefingSkill 之前调用 weather.extractCity，weather.extractForeignCity 把整句（含"今天出门要带伞"）当城市名传给 geocoding，UTF-8 字节被乱码解读
- **修复**：WeatherBriefingSkill 用 extractCitySafe + 已知城市白名单（KNOWN_CITIES，长度倒序匹配）；删掉"取第一个非停用词汉字"fallback（容易误吃虚词）
- **坑**：第一次 Edit 时 new_string 太大（13KB），KNOWN_CITIES/STOP_HAN 块没成功加进文件——Edit 报"successful"但内容丢失。教训：Edit 大块内容用 Read+Write 重写，**别只信 Edit 返回**；编译要看 `error` 行（grep "warning|警告" 会漏掉中文"错误"）
- 编译失败时单独编译（不加 grep 过滤）才能看到真实错误

### 问题 3：3 个音色说 3 遍你好，只有 1 个声音
- **根因**：MULTI_VOICE_PATTERN 没匹配"用三个音色分别和我说，你好"——(?:分别|都|各)? 吃"分别"后回溯失败
- **修复**：BotMain MULTI_VOICE_PATTERN 改 `(?:(?:分别|都|各)?和?(?:我|你)?)?` 让"和我说"也能命中

### 问题 4：作息只记最后 1 个时段
- **根因**：RoutineSkill.set() 直接覆盖 workStart/workEnd——多时段时 part[2] 覆盖 part[0]
- **修复**：加 `&& workStart == null` 守卫，只设第一个匹配（作息字段只支持单一时间，多时段无意义）

### 问题 5：提醒不弹
- **根因**：scheduler 启动后 30s 才第一次跑 + 30s 周期；提醒可能"卡"在两次检查之间漏过
- **修复**：initialDelay=5s, period=10s（提醒检查）；每日关怀 30s（精确捕捉 7:30/19:30/10:00/15:00）

### 额外修复：提醒内容残留"的时候"
