我们小组是第26组，项目名称为"智能微信助手"。
机器人使用 Java 语言开发，基于微信 iLink SDK 实现消息收发。

机器人支持的功能包括：天气查询、多语言翻译、算术计算、单位换算、AI 画图、语音回复。
天气查询使用 Open-Meteo 免费天气服务，支持中文、英文、德文、法文、日文、韩文问法。
翻译功能使用 MyMemory 翻译服务，支持中文、英文、日语、韩语、法语、德语等 13 种语言。
计算功能支持四则运算、括号、幂运算、开方、中文运算符。
单位换算支持长度和重量两类，长度单位有米、千米、公里、厘米、毫米、英尺、英寸、英里，重量单位有克、千克、公斤、吨、斤、磅、盎司。

对话功能基于阿里云百炼 qwen-plus 大模型。
语音回复使用阿里云 CosyVoice 语音合成，把回复文字合成为语音发给用户。
画图功能使用通义万相模型，用户说"画一只猫"即可生成图片。
