### 关键技术发现
1. **SDK 正确 API**：
   - 创建客户端：`ILinkClient.builder().config(config).onLogin(...).onMessage(...).build()`（不是 `ILinkClientBuilder.builder()`）
   - 消息类是 `WeixinMessage`（不是 WechatMessage），字段是 `getFrom_user_id()`、`getItem_list()`
   - 文本内容需从 `item.getText_item().getText()` 提取，没有 `msg.getText()`
   - `ILinkConfig.Builder` 没有 `clawBotEndpoint`/`clawCode` 方法
   - `executeLogin()` 返回二维码 base64，需 `getLoginFuture().get()` 等待登录完成，之后主循环调 `getUpdates()` 拉消息

2. **环境问题（重要）**：
   - 系统 `JAVA_HOME` 指向不存在的 `D:\jdk-21.0.12`，`CLASSPATH` 也指向它，导致 mvn 脚本启动失败
   - 可用 JDK 在 `D:/Java/jdk17`
   - mvn shell 脚本的 cygpath 路径转换有问题，直接用 java 命令启动 maven 绕过：
     ```
     env -u CLASSPATH "D:/Java/jdk17/bin/java" \
       -Dmaven.multiModuleProjectDirectory="<项目绝对路径>" \
       -Dmaven.home="D:/Java/apache-maven-3.8.8" \
       -Dclassworlds.conf="D:/Java/apache-maven-3.8.8/bin/m2.conf" \
       -classpath "D:/Java/apache-maven-3.8.8/boot/plexus-classworlds-2.6.0.jar" \
       org.codehaus.plexus.classworlds.launcher.Launcher -q clean compile
     ```

15. **语音气泡未成功发送根因：格式不匹配 + 修复（2026-08-17 17:45）**：
   - 用户运行 BotMain 后发语音消息，日志显示 TTS 合成成功（"合成完成 22291 字节，发送语音回复"），但微信聊天里 bot 仍然回文字
   - 根因：SDK `MessageService.sendVoice()` 默认 `encode_type=6`（SILK 编码），且 README 示例明确用 `demo.silk`；而 CosyVoice 返回的是 MP3/WAV，直接发送会被微信服务端拒绝/忽略
   - 修复：新增 `AudioConverter.java`（com.github.wechat.ilink.sdk.bot 包），调用外部 ffmpeg + ffprobe 把 TTS 音频转成 16kHz 单声道 SILK，并获取播放时长（ms）
   - 修改 `BotMain.handleVoice()`：TTS 后先 `audioConverter.toSilk(audio, "mp3")`，再 `client.sendVoice(fromUserId, silk.bytes, "voice.silk", silk.playTimeMs, silk.sampleRate)`
   - `ai-bot.properties` 新增 `ai.ffmpeg-path` / `ai.ffprobe-path` 配置，默认从 PATH 和常见安装路径自动查找
   - 编译通过（BUILD SUCCESS）。用户下一步：安装 ffmpeg 到 Windows PATH 后重启 IDEA，再运行 BotMain 测试语音气泡
